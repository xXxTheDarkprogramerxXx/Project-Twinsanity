# Project Twinsanity

> A fan-made recreation of **Crash Twinsanity**, rebuilt from the ground up in **Unity**.

## About

**Project Twinsanity** is a fan-made recreation of *Crash Twinsanity* focused on rebuilding the original game as faithfully as possible in a modern Unity environment.

The goal is to preserve what made the original game memorable — its strange humour, open-ended levels, character interactions, soundtrack, platforming, and chaotic Crash/Cortex partnership — while recreating the underlying systems in a clean and expandable modern game project.

Rather than simply reproducing the visuals, Project Twinsanity aims to reconstruct the actual gameplay experience: movement, animation, enemies, collectibles, checkpoints, masks, level logic, scripted events, cameras, cutscenes, and the many small details that gave the original game its personality.

## Project Goals

- Recreate the original Crash Twinsanity levels in Unity.
- Rebuild Crash's movement and gameplay mechanics.
- Reconstruct the original character rigs and animations.
- Accurately import and display original game models, textures, and environments.
- Recreate enemies, crates, collectibles, checkpoints, hazards, and interactive objects.
- Implement Aku Aku masks and the original protection system.
- Rebuild scripted level events and gameplay sequences.
- Recreate Crash and Cortex gameplay interactions.
- Preserve the visual style and atmosphere of the original game.
- Build reusable Unity systems that make restoring additional levels easier over time.

## Current Development

Project Twinsanity is currently in active development.

Major areas being worked on include:

- Original Twinsanity asset importing
- PS2/RM2 model and animation conversion
- Character rig reconstruction
- Crash movement and animation
- Level reconstruction
- Checkpoint systems
- Aku Aku pickups
- Collectibles and crates
- Original-style shaders
- Cameras and gameplay scripting

The project is being developed incrementally, with each system recreated and tested against the behaviour of the original game.

## Philosophy

The aim of Project Twinsanity is **faithful reconstruction first**.

Where possible, gameplay behaviour, animation, level layouts, timing, object placement, and mechanics should match the original game.

Modern improvements may be introduced where they improve compatibility, stability, tooling, or usability without changing the identity of the original experience.

## Technology

Project Twinsanity is built using:

- **Unity**
- **C#**
- Custom importers and conversion tools for original Twinsanity assets
- Custom shaders designed to reproduce the visual appearance of the original game

## Why Project Twinsanity?

*Crash Twinsanity* is remembered for being ambitious, unusual, funny, and full of personality.

It was also a game with a famously difficult development history, leaving behind unused concepts, unfinished ideas, cut content, and systems that were never fully realised.

Project Twinsanity is a passion project created to explore, understand, preserve, and rebuild that experience using modern tools.
